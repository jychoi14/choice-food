# 🍜 오늘 뭐 먹지? (What Should I Eat Today?)

"결정 장애를 위한 최고의 메뉴 추천 서비스!"

기존의 단순한 번호 생성기에서 벗어나, 매일 반복되는 "오늘 뭐 먹지?"라는 고민을 즐겁고 빠르게 해결해주는 웹 애플리케이션입니다.

## ✨ 주요 기능

- **슬롯머신 애니메이션**: 버튼을 누르면 다양한 메뉴들이 빠르게 회전하며 긴장감 넘치는 추천 과정을 보여줍니다.
- **카테고리 필터링**: 한식, 중식, 일식, 양식, 분식, 디저트 등 원하는 종류만 쏙 골라서 추천받을 수 있습니다.
- **실감 나는 효과음**: 메뉴가 돌아갈 때의 틱 사운드와 당첨 시의 팡파르 사운드로 재미를 더했습니다.
- **최근 기록 저장**: 최근에 어떤 메뉴를 추천받았는지 브라우저에 자동으로 저장되어 나중에 확인할 수 있습니다.
- **반응형 디자인 & 다크 모드**: 모바일에서도 완벽하게 작동하며, 눈이 편안한 다크 모드를 지원합니다.
- **제휴 및 문의 (Formspree 연동)**: Formspree API(`https://formspree.io/f/xoeawaql`)를 연동하여 깔끔하고 세련된 제휴 문의 폼을 제공합니다. 다국어 지원 및 AJAX 비동기 전송을 처리하여 뛰어난 사용자 경험을 제공합니다.

## 🛠 사용 기술

- **Frontend**: HTML5, CSS3 (Vanilla CSS), JavaScript (ES6+)
- **Audio**: Web Audio API를 활용한 동적 효과음 생성
- **Storage**: 브라우저 로컬 스토리지 (LocalStorage)를 이용한 데이터 유지

## 🚀 시작하기

1. `index.html` 파일을 브라우저로 엽니다.
2. 원하는 카테고리를 선택합니다.
3. **"추천해줘!"** 버튼을 눌러 오늘의 운명 메뉴를 확인하세요!
